# Week 2 - User Authentication System

## 📌 Overview
This project is a User Management System built using Node.js, Express, and MongoDB.  
In Week 2, we implemented secure authentication and improved application security.

---

## 🚀 Features
- User Registration
- User Login
- JWT Authentication
- Password Hashing using bcrypt
- Protected Routes (Middleware)
- MongoDB Database Integration

---

## 🔐 Security Implemented
- Passwords are hashed before saving in database
- JWT token used for authentication
- Protected routes using verify middleware
- Input validation added

---

## 🧪 Testing Performed
- Tested user registration via Postman
- Tested login and token generation
- Accessed protected route using JWT token
- Verified password hashing in MongoDB

---

## 📂 Tech Stack
- Node.js
- Express.js
- MongoDB
- JWT
- bcrypt

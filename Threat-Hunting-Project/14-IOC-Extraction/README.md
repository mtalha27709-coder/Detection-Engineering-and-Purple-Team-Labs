# IOC Extraction Report

## Objective

The objective of this phase was to extract and document Indicators of Compromise (IOCs) identified during threat hunting and investigation activities.

IOC extraction helps security analysts identify artifacts associated with suspicious behavior and provides valuable information for:

- Threat hunting
- Incident investigation
- Detection rule development
- Threat intelligence enrichment
- Future security monitoring

The extracted indicators were collected from endpoint telemetry generated by Sysmon and analyzed through Wazuh SIEM.

---

# IOC Extraction Environment

| Component | Description |
|----------|-------------|
| SIEM | Wazuh |
| Endpoint | Windows 10 |
| Telemetry Source | Sysmon |
| Investigation Platform | Wazuh Dashboard |
| Attack Simulation | Atomic Red Team |

---

# IOC Extraction Methodology

The following workflow was followed during IOC extraction:

1. Execute controlled attack simulations.
2. Collect Sysmon telemetry.
3. Review Wazuh alerts and events.
4. Analyze suspicious processes.
5. Extract relevant artifacts.
6. Categorize extracted indicators.
7. Document findings.
8. Use extracted IOCs for detection improvement.

---

# IOC Categories

## 1. Process-Based Indicators

Process execution artifacts were collected from Sysmon Event ID 1.

### Examples:

| Indicator Type | Example |
|---|---|
| Process Name | powershell.exe |
| Process Name | mshta.exe |
| Process Name | certutil.exe |
| Parent Process | cmd.exe |
| Command Line | Encoded PowerShell command |

### Purpose

Process-based IOCs help identify suspicious execution behavior and possible LOLBin abuse.

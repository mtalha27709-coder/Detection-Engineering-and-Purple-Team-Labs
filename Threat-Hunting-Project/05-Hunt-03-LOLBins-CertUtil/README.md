# Hunt 03 – LOLBins (CertUtil)

## Objective

The objective of this hunt was to identify the abuse of Windows Living-Off-the-Land Binaries (LOLBins), specifically **CertUtil.exe**, which is commonly abused by attackers to download, encode/decode, or transfer malicious payloads while blending in with legitimate Windows activity.

---

## Hunt Hypothesis

An attacker may abuse **CertUtil.exe** to execute malicious activities such as downloading payloads or decoding files. These actions should generate process creation events that can be identified using Sysmon and investigated through Wazuh.

---

## Environment

- SIEM: Wazuh
- Endpoint: Windows 10
- Logging: Sysmon Event ID 1 (Process Creation)
- Attack Machine: Windows 10
- Detection Source: Sysmon + Wazuh

---

## Attack Simulation

The LOLBin activity was simulated using **Atomic Red Team**.

**MITRE ATT&CK Technique**

- **T1218.010 – Signed Binary Proxy Execution: CertUtil**

Example execution:

```powershell
Invoke-AtomicTest T1218.010 -PathToAtomicsFolder $PathToAtomicsFolder
```

---

## Investigation Process

The hunt focused on identifying executions of **CertUtil.exe** by searching process creation events generated by Sysmon.

### Wazuh Hunt Queries

```text
data.win.eventdata.image:*certutil.exe
```

```text
data.win.eventdata.commandLine:*certutil*
```

```text
certutil
```

---

## Evidence Collected

The investigation confirmed the execution of **CertUtil.exe**.

Observed artifacts included:

- Process Name: certutil.exe
- Command Line Arguments
- Parent Process
- User Account
- Execution Time
- Sysmon Event ID 1

---

## Detection Analysis

The activity was successfully detected by Sysmon and forwarded to Wazuh.

Key observations:

- CertUtil execution was visible.
- Full command-line arguments were recorded.
- Parent-child process relationship was available.
- Timeline reconstruction was possible using Wazuh logs.

## Conclusion

This hunt demonstrated how attackers can abuse **CertUtil.exe**, a legitimate Windows utility, to perform malicious actions while attempting to evade detection.

Using Sysmon process creation logs and Wazuh, the activity was successfully identified, investigated, and mapped to the MITRE ATT&CK framework. This highlights the importance of monitoring LOLBins as part of proactive threat hunting and detection engineering.

## Overview

This repository contains my Detection Engineering and Purple Team portfolio developed through hands-on cybersecurity labs.

The objective of these projects is to simulate real-world attacker behavior, develop detections, investigate security events, map findings to the MITRE ATT&CK Framework, and validate defensive capabilities.

The labs focus on improving Blue Team detection capabilities while understanding offensive techniques used by adversaries.

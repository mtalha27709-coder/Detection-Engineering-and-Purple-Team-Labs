# Conclusion

## Project Summary

The **Active Directory Attack & Detection Lab** successfully demonstrated a complete Purple Team workflow by combining offensive attack simulation with defensive monitoring and investigation.

Throughout this project, multiple Active Directory attack techniques were executed from Kali Linux against a Windows Server 2022 Domain Controller. Each attack was analyzed from a Blue Team perspective using Windows Security Logs, Sysmon, and Wazuh SIEM to understand how attackers operate and how defenders can identify malicious activity.

---

## Key Achievements

The following attack techniques were successfully completed:

- BloodHound Active Directory Enumeration
- Kerberoasting
- Pass-the-Hash
- DCSync

Each attack was documented with objectives, execution steps, detection methods, investigation findings, and MITRE ATT&CK mappings.

## Lessons Learned

Throughout this project, several important lessons were learned:

- Active Directory remains one of the primary targets for enterprise attackers.
- Windows Security Logs provide valuable forensic evidence when properly monitored.
- Sysmon significantly improves endpoint visibility.
- Wazuh enables centralized monitoring and investigation of suspicious activity.
- MITRE ATT&CK provides a standardized framework for understanding attacker behavior.
- Combining offensive testing with defensive monitoring creates a more realistic Purple Team workflow.

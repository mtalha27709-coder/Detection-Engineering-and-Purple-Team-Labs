# 03 - Wazuh Configuration

## Objective

The objective of this phase was to validate the Wazuh SIEM deployment and ensure that endpoint logs generated by the Windows 10 machine were successfully collected, processed, and displayed within the Wazuh Dashboard.

## Overview

After completing the lab setup and installing Sysmon, Wazuh was configured to provide centralized log collection and security monitoring. The Windows endpoint was connected to the Wazuh Manager through the Wazuh Agent, allowing security events to be forwarded in real time.

## Components Used

- Wazuh Manager
- Wazuh Dashboard
- Wazuh Agent
- Windows 10 Endpoint
- Sysmon

## Configuration & Validation

The following tasks were completed during this phase:

- Logged into the Wazuh Dashboard.
- Verified that the Wazuh Manager was operational.
- Confirmed that the Windows endpoint was connected as an active agent.
- Verified successful communication between the Wazuh Agent and Wazuh Manager.
- Opened the Threat Hunting dashboard to monitor incoming events.
- Confirmed that Windows security events were successfully received and displayed.
- Verified generated alerts, Rule IDs, Severity Levels, and Event Descriptions.

## Result

The Wazuh SIEM environment was successfully configured and validated. Endpoint logs generated by the Windows 10 system are now being collected and analyzed in real time. The monitoring infrastructure is fully operational and ready for Purple Team attack simulations, threat detection, and incident investigation.

# Install Wazuh Manager and Agent

## Objective

Deploy Wazuh SIEM to collect and monitor endpoint security events.

## Steps Performed

- Installed Wazuh Manager
- Verified dashboard access
- Installed the Wazuh Agent on the Windows endpoint
- Connected the agent to the manager

## Outcome

The Windows endpoint successfully reports security events to the Wazuh Manager, enabling centralized monitoring and threat detection.

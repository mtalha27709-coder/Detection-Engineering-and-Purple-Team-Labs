# 03 - Wazuh

## Overview

Wazuh is an open-source Security Information and Event Management (SIEM) and Extended Detection and Response (XDR) platform used to collect, analyze, and detect security events from monitored endpoints.

In this Detection Engineering Lab, Wazuh serves as the central detection platform. It receives Windows event logs and Sysmon telemetry from the Windows endpoint, processes them using built-in and custom detection rules, maps alerts to the MITRE ATT&CK framework, and presents the results in the Wazuh Dashboard.

---

# Objectives

- Verify Wazuh Manager operation
- Confirm communication between the Windows endpoint and Wazuh
- Validate Sysmon log collection
- Observe security alerts in the Wazuh Dashboard
- Prepare the platform for custom Detection Engineering rules

---

# Lab Components

| Component | Purpose |
|-----------|---------|
| Wazuh Manager | Collect and analyze logs |
| Wazuh Dashboard | Visualize alerts and investigations |
| Wazuh Agent | Forward endpoint logs |
| Sysmon | Generate Windows security telemetry |
| Windows 10 | Monitored endpoint |

---

# Verification

The following checks were performed during lab validation.

### Verify Wazuh Manager

```bash
sudo systemctl status wazuh-manager
```

### View Registered Agents

```bash
sudo /var/ossec/bin/agent_control -l
```

### View Custom Rules

```bash
cat /var/ossec/etc/rules/local_rules.xml
```

### Monitor Wazuh Logs

```bash
sudo tail -f /var/ossec/logs/ossec.log
```

---

# Detection Validation

After generating Windows activities using Sysmon, the logs were successfully forwarded to the Wazuh Manager.

The Wazuh Dashboard displayed security alerts generated from these events, confirming that the detection pipeline was functioning correctly.

Example detections included:

- Process execution
- File creation
- Registry modification
- DNS activity

---

# MITRE ATT&CK Mapping

The generated alerts were automatically mapped to the MITRE ATT&CK framework.

Example techniques observed:

- T1112 – Modify Registry
- T1565.001 – Stored Data Manipulation

These mappings demonstrate that Wazuh successfully correlates endpoint telemetry with ATT&CK techniques, providing valuable context for security investigations.
